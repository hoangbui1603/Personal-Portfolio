# Hoang Bui — Portfolio

Personal portfolio website of **Hoang Bui**, a Computer Science student at the University of North Texas.

**Built with:** HTML5, Bootstrap 5, CSS3, and vanilla JavaScript.
**Hosted on:** AWS Amplify.

## Run locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

## Deploy

Push to the `main` branch on GitHub. AWS Amplify redeploys the site automatically.
